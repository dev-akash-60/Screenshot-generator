# 📸 Website Screenshot Generator

A full-stack web application that captures screenshots of any website using **Node.js, Express, and Puppeteer**.

---

## 🚀 Features

- 🌐 Capture screenshots of any website URL  
- 📱 Full-page screenshot support  
- ⚡ Fast rendering using Puppeteer  
- 🎨 Animated UI  
- 💾 Download screenshots  
- 🔗 Share screenshots  
- 🌙 Responsive design  

---

## 🛠️ Tech Stack

- Frontend: HTML, CSS, JavaScript  
- Backend: Node.js, Express  
- Automation: Puppeteer  

---

## 📂 Project Structure
```
Screenshot Generator webapp/

```
## 🧠 Usage
- Enter a valid URL (with https://)
- Click Capture
- Wait for processing
- Download or share screenshot
